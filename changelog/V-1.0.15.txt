What's New:

	- builtins:
		- added getterm() and setterm(state)
		- bug: fwrite: fix arg order in InvalidArgCountHint

	- corelib:
		- libbytes.chh added
		- libtermios.chh: renamed to libterm.chh
		- libterm.chh: added termios field offset constants (TIFLAG, TOFLAG, TCFLAG, TLFLAG, TVMIN, TVTIME)
		- libterm.chh: added termios flag constants (IGNBRK, BRKINT, PARMRK, ISTRIP, INLCR, IGNCR, ICRNL, IXON, OPOST, CSIZE, PARENB, CS8, ISIG, ICANON, ECHO, ECHONL, IEXTEN)
		- libterm.chh: added SetBGColor256, SetFGColor256, SetBGColorRGB, SetFGColorRGB
		- libterm.chh: added DTSZ sequence
		- libterm.chh: added MakeRaw(state)
		- libterm.chh: GetTerminalSize() rewritten to use getterm/setterm instead of stty
		- libhash.chh: BytesToHex moved to libbytes.chh
		- libinput.chh: InputPw() rewritten to use getterm/setterm instead of stty

	- rr2:
		- bitwise operators added: band, bor, bnot, bxor
		- shift operators added: <<, >>
		- xor operator added
		- band, bor, bnot, bxor, xor are now reserved keywords

	- misc:
		- demo for 8-bit terminal colors added under misc/colorcube
		- documentation for operators added

FYI Breaking: libtermios.chh is no longer a thing, have your program use libterm.chh instead, the API is the same so no code changes are needed.
If you used BytesToHex(bytes) from libhash.chh, you now need to load libbytes.chh instead.
band, bor, bnot, bxor, and xor can no longer be used as variable or parameter names (chippy check will flag those in your code).
